Coworkers are optional persistent specialist identities. Ordinary conversations require no Coworker. A selected native chief agent owns reasoning while LiteCowork owns durable Task, permission, trigger, Effect and evidence truth.

  • Chat remains the primary surface.
  • Connections are optional during creation and can be added later.
  • Automatic memory is quiet, scoped and independent of proactive authority.
  • Responsibilities group existing Goal, Routine and Automation concepts without creating a second workflow engine.
