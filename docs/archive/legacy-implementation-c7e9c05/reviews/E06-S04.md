## What was implemented

Local models are **inventory only**. LiteCowork has no global Providers feature. A
local model becomes selectable only through an Agent, and only when that Agent's
AgentModule reports compatibility for the exact model.

### Rules (`crates/domain-rag/src/local_model.rs`)

- `LocalModelAvailability::not_configured` is the fail-closed availability used until a
  qualified local provider exists. It reports `NOT_CONFIGURED`,
  `LOCAL_MODEL_PROVIDER_NOT_QUALIFIED`, `inventory_only = true`, `surface =
  "AGENT_SCOPED"`, and `agent_binding_policy = "AGENT_MODULE_COMPATIBILITY_REQUIRED"`.
- `resolve_local_model_state` maps one inventory entry plus one AgentModule
  compatibility record to `INVENTORY_ONLY`, `AGENT_COMPATIBLE`, or
  `AGENT_INCOMPATIBLE`. A model without a matching compatibility record is
  `INVENTORY_ONLY`; a compatibility record for another model never applies.
- `agent_module_compatible` is the exact check an Agent uses before offering a model.

### Route (`apps/litecoworkd/src/rag_local_model_operator.rs`)

```text
GET /v1/capabilities/local-models
```

It requires the selected Workspace header and the authenticated Workspace owner and
returns the inventory and the policy only. It never probes an endpoint, never accepts an
Agent- or document-supplied URL, never returns a credential, and never claims that an
engine present on the machine is connected or authorized. The response is
`Cache-Control: no-store`.

```json
{
  "capabilityId": "litecowork.local-models",
  "status": "NOT_CONFIGURED",
  "reasonCode": "LOCAL_MODEL_PROVIDER_NOT_QUALIFIED",
  "reason": "No qualified local inference provider is registered. Local models stay inventory only and are offered through an Agent when its AgentModule reports compatibility.",
  "inventoryOnly": true,
  "surface": "AGENT_SCOPED",
  "agentBindingPolicy": "AGENT_MODULE_COMPATIBILITY_REQUIRED",
  "models": []
}
```

### Desktop rules (`apps/litecowork-ui/src/resources/local-model-inventory.ts`)

The decoder refuses a payload that is not inventory only, or that presents local
models outside an Agent surface. `localModelIsUsableByAgent` returns true only for an
exact AgentModule/model match that reports compatibility.

## The admission gate is not satisfied

`docs/NETWORK-SECURITY.md` and the E06 admission gate require an owner-controlled
endpoint record and an exact local service binding through the trusted Runtime broker
before endpoint readiness or model discovery can ship. **That gate is not satisfied.**
Until it is:

- the UI must report `UNAVAILABLE` / `NOT_CONFIGURED`;
- no endpoint may be probed;
- no model may be offered to a Task;
- Ollama, LM Studio, and llama.cpp remain qualification candidates only.

The implemented route does exactly that: it reports the fail-closed state and never
probes.
