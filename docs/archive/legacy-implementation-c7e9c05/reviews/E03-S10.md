## Implemented slice

`apps/litecowork-ui/src/conversations/conversation-agent-surface.ts` now keeps the composer
projection fail-closed unless the descriptor and its installation observation are fresh,
refer to the same registry agent/module, identify a Runtime and incarnation, and report an
installed agent (`INSTALLED` or `UPDATE_AVAILABLE`). A missing, broken, expired, or
mismatched installation observation requires descriptor refresh. An available update does
not invalidate the currently installed descriptor before its expiry.

The agent-switch reducer now clears agent-owned session options if the binding changes or
its descriptor digest changes. User draft text and attachments remain in the same
Workspace/Conversation scope. Native tokens must still belong to the selected binding and
fresh descriptor, match the current descriptor's command ID and literal syntax (or reference
kind and trigger), and point to the same exact text range in the current draft. Stale tokens
remain visible as literal draft text and block compatibility.
