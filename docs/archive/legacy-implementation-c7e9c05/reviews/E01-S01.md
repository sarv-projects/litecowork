## Pinned-toolchain gate behaviour and fast preflight — 2026-10-20

`scripts/check.sh` keeps the same verified stages in the same order, and now reports and
guards them more precisely.

- A **missing** pinned tool is reported by name and pin
  (`Required pinned tool uv was not found on PATH.` / `Install uv 0.12.23 before running
  scripts/check.sh.`) instead of a bare shell `command not found`. The version mismatch
  messages are unchanged: `Expected uv 0.12.23, found 0.0.0`, `Expected Rust 1.98.1, found
  0.0.0`, `Expected Cargo 1.98.1, found 0.0.0`, `Expected Python 3.13.12, found 3.12.0`.
- The locked Python environment is synchronized with `uv sync --locked` and retried with
  `uv sync --locked --offline` when the network-backed sync fails, so an offline host with a
  warm uv cache can still run the gate. The resolved interpreter is then **proved** to be an
  isolated environment: the gate compares `sys.prefix` with `sys.base_prefix` and fails
  closed with `Expected an isolated pinned Python environment, found a floating interpreter
  at <path>.` A floating system interpreter is therefore rejected, and the gate prints the
  environment it used (`Python environment: <prefix>`). The gate still never invokes a
  system `python3`.
- Every stage prints its label and wall-clock duration (`==> Python tests` /
  `Python tests passed in 23s`), so a slow run is attributable to a stage instead of
  looking like a hung gate. A failing stage prints its exit status and the gate still
  fails.
- `scripts/check.sh --preflight` runs the toolchain checks, the Python tests, and all
  contract validators **without** the Rust format/lint/test/build stages. It is the fast
  inner loop for a shared development host and is the only mode that proves the gate can be
  run quickly.
- `LITECOWORK_CARGO_JOBS` optionally bounds Cargo parallelism (`--jobs N`) for shared
  hosts. When it is unset the Cargo default is used, so CI behavior is unchanged.
- `scripts/check.sh --help` prints the usage; an unsupported argument exits **2** without
  running any stage.
