## Implemented slice

`apps/litecoworkd/src/environment_office_qualification.rs` implements the *rules* that
E07-S04 requires of an external office/data provider. It is a qualification gate, not a
provider: it decides whether a declared provider may be offered, and it refuses unsafe
or unverifiable inputs.

**Formula and rendered-layout checks are independent.** `qualify_office_provider`
refuses a declaration whose `formula_engine` and `layout_engine` are the same
(`ChecksNotIndependent`), and refuses a declaration that does not perform both checks
(`FormulaCheckNotEnforced`, `LayoutCheckNotEnforced`). A single engine cannot certify
both, because the same defect that produces a wrong formula usually produces a
plausible-looking render.

**Source and provenance are pinned.** `PinnedProvenance` binds an output to an exact
Resource, revision, and content digest. `verify_provenance` refuses an output with no
claimed source (`UnpinnedProvenance`) and refuses one that names a source that was not
pinned (`UnknownProvenance`).

**Generated code or capability is a reviewed draft only.** `GeneratedOfficeCapability`
always starts as `ReviewStatus::Draft`, and
`request_generated_capability_approval` returns `OwnerReviewRequired`: the producer of
a generated capability can never approve it.

**Negative cases.** `detect_executable_content` refuses an OOXML package that carries a
VBA project, an OLE compound file, and a PDF that carries `/JavaScript`, `/OpenAction`,
`/Launch`, or `/EmbeddedFile`. `validate_tabular_source` refuses a truncated CSV (an
unterminated quoted field, or an inconsistent column count between rows) and a source
over its byte/row/column bounds. `validate_formula_syntax` refuses an unbalanced
formula, an unterminated string, and a formula without a leading `=`.
`check_rendered_layout` refuses a missing required font (`FontUnavailable`) and a
render that produced no page (`ExportFailed`).

**Truthful availability.** `probe_office_providers` reports all five formats
(XLSX, DOCX, PPTX, PDF, CSV) as `NotEnforced` for both checks and not editable, with the
reason stated in `notes`. The product must not show a workbook or slide capability that
this build cannot produce.

## Contracts

- [E07-S04](../epics/E07.md#e07-s04-office-dataresearch-capability-qualification) owns

- [ENVIRONMENTS](../../docs/ENVIRONMENTS.md#built-in-provider-classes) keeps external
  implementations as capabilities/providers rather than Core concerns.
- [ARTIFACTS-EVIDENCE](../../docs/ARTIFACTS-EVIDENCE.md) owns the immutable artifact
  and its provenance; this module only pins the source reference.

  package endpoint, method, or schema is invented here.
