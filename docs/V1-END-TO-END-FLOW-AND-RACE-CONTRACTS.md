# V1 End-to-End Flow, Admission and Race-Condition Verification Contracts

Status: normative TARGET cross-owner design crosswalk. Canonical states, machine enums, operation IDs, event names and SQLite transactions remain in STATE-MACHINES, API/OpenAPI, EVENTS, STORAGE and TASK-RUNTIME. This ledger defines handoffs and negative-condition acceptance; it does not pretend unserved candidate routes exist. Every chain must be demonstrated in source and UIV1 plus canonical UAT before release.

## General end-to-end proof obligation

Each path must identify (1) initiating user/schedule intent and Workspace Principal, (2) required grants and immutable input pins, (3) admission owner and expected version, (4) persisted receipt/domain record/outbox transaction, (5) actual provider operation with lease and effect identity if applicable, (6) observed/reconciled outcome, (7) independent acceptance Evidence, (8) authorized projected UI display, (9) bounded recovery if interrupted. UI success animation never substitutes for step 4/7.

## Adversarial interleavings and required owner outcome

| Race/partial failure | Exact fencing/reconciliation condition | Forbidden behavior | Test evidence |
|---|---|---|---|
| Workspace switches while list/descriptor/stream request is pending | UI Workspace epoch + response owner compare | Render results or draft from previous Workspace | UIV1-003 |
| Two windows change one binding default | Optimistic Workspace/Coworker version CAS and rerender from winner | Silent last-writer-wins without conflict | UIV1-023, UIV1-042 |
| Native agent switched while Send queued | Bound immutable draft snapshot to selected AgentBinding and descriptor digest at admission | Dispatch with mixed old model/new agent | UIV1-023–036 |
| User presses Send twice or reconnects | Stable Idempotency-Key with canonical committed turn identity | Two ConversationTurns/side effects | UIV1-016–020 |
| User cancels native turn as completion races | AgentTurnCoordinator terminal transition version CAS | Mark CANCELLED when provider completed first; append late final twice | UIV1-020–022 |
| Native command catalog changes between picker and Send | Descriptor incarnation/digest compare; refresh/explicit repair | Execute old custom command with new meaning | UIV1-028–036 |
| Planning completion races with user edit | TaskSpecRevision pin and PlanRevision acceptance CAS | Admit Step under obsolete TaskSpec | UIV1-091–092 |
| Two worker schedulers reserve same Step | Atomic Step/Attempt/lease admission guarded by expected plan and readiness | Parallel authoritative Attempts on one Step | UIV1-092–100 |
| Worker returns after lease expiration | Attempt+Runtime incarnation+lease fencing | Commit late stale evidence as Step success | UIV1-093, UIV1-098 |
| Tool request timeout after real external mutation | Persist ambiguous Effect and reconcile provider receipt using same key | Re-send with new request identity | UIV1-094, UIV1-111 |
| Revocation while child Attempt running | Future invoke admissions denied immediately; already external effects require reconciliation | Retroactive claim external effect never happened | UIV1-114 |
| Browser transfer during pending agent click | Epoch CAS; cancellation fence + no later agent input | Agent click after USER gains control | UIV1-082 |
| User edits form while browser observer stale | Fresh observation revision and origin reauth before return | Replay stale selector or auto-submit | UIV1-083–084 |
| Redirect to new origin mid-action | Allowed-origin gate on every redirect/reentry | Follow into unauthorized origin | UIV1-087 |
| Chrome/profile detached while worker holds lease | Provider session incarnation revocation, action becomes unavailable | Keep sending CDP commands after revocation | UIV1-077–081 |
| RichPresentation fails digest/sanitizer | Preserve semantic message and report degraded optional rich layer | Hide committed response or execute untrusted script | UIV1-053–057 |
| Artifact edited by second window during publish | Immutable ArtifactVersion and If-Match CAS | Overwrite winner silently or lose draft | UIV1-059–060 |
| Routine saved concurrently with trigger fire | Occurrence bound to explicit immutable RoutineRevision | Execute partially saved routine | UIV1-128–139 |
| DST fold and duplicate delivery | Stable trigger/slot/event identity; host cursor and skip policy | Twice execute one intended slot | UIV1-128–139 |
| Laptop closes during local schedule | Trigger history records missed/blocked/observed on wake per configured rule | Pretend cloud execution happened | UIV1-130–139 |
| Approval given from two app windows | Request version CAS; provider confirmation fences user-response continuation | Double-apply or resume with rejected input | UIV1-140–147 |
| Workspace archive races with pending AutomationCursor | Require durable host drain and absent cursor before archive transaction | Archive active source with scheduled future work | UIV1-007–009 |
| Runtime restart during profile import/backup/cleanup | Staged digest, idempotency receipt, resume/reconcile or rollback | Delete source/native profile or partially overwrite silently | UIV1-074–075, UIV1-155–158 |
| Credential or Context source revoked mid-use | Trust check at new admission; snapshot source provenance and invalidate future use | Leak bearer secrets or widen grants | UIV1-110–127 |

## Verification and promotion discipline

All 25 flow chains and 24 race classes are design acceptance targets, not achieved results. Owner must record exact canonical API operationId (or new proposal requiring promotion), event type/schema, transaction, Task/Turn/Effect state edge, UI reducer action, source fixture, and positive/negative proof in the owning epic before marking VERIFIED. No event family, browser route, layout preference route or new enum is promoted by writing this file. The first-party UI does not yet implement native Send and actual browser takeover; do not report them as shipped.
