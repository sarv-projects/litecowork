## Cross-cutting observations

- Layer discipline holds: `domain-*` crates take only `serde` (plus `time`/`serde_json` for domain-task) — no storage, no provider, no I/O. `storage-core` declares ports and records with no `rusqlite`/`tokio`/`keyring`. `storage-sqlite` owns transactions, blobs, SQLite clock and OS keyring. `windows-local-security` owns unsafe Win32. No generic root `src/`, matching ARCHITECTURE.md §7.
- Fail-closed is explicit, not accidental: `admit_step_attempt`, `renew_execution_lease`, `release_execution_lease`, planning-session start/activate, and `WORKSPACE_PERSISTENT` Environment creation all return typed errors naming the missing proof (Environment containment, Trust grant, budget reservation, Effect reconciliation, private Runtime control receipt, typed preview consumption). No path fabricates a success, an "assumed" grant, or a zero-cost/zero-latency default.
- "Unknown is not success" is encoded in types: `AttemptAdmissionChecks` mostly `Unsupported`; `budget_admission = Unsupported`; `ChildAttemptAdmissionProofs::default()`; B83 missing verifications reduce coverage and never count as pass; unknown/expired/low-confidence cost observations remain `unknown_cost_profile_ids`; Goal progress reports `availability = Partial` with named limitations; drift without observation is `Unknown`, not `Healthy`.
- Identity distinctness is enforced by construction: `EnvironmentIdentity.created_by_incarnation_id` is creation-only; `RuntimeIncarnationId` is fenced in SQL (`EXECUTION_LEASE_STALE_RUNTIME_INCARNATION`); native handles (`native_session_ref`, `private_locator`, `raw_file_id`, provider locator) are non-Serde or `#[serde(skip)]` with redacting `Debug`; app-frame nonce never reaches the event journal; `AgentSessionRecord` has no resume handle.
- Idempotency pattern is uniform: `(principal_id, request_id)` row in `request_dedup` carrying `request_digest` + `response_json` + `response_digest`; replay is resolved **before** mutable admission state is read; digest mismatch ⇒ conflict/`Integrity`. Deterministic event ids (`ev_<digest>`, `sug_exp_<digest>`) make expiry/preference retries naturally idempotent.
- Blob-before-transaction is the standard write shape (goals, suggestions, skill, expire_execution_lease): write aggregate state to the CAS, verify by re-read, then open an IMMEDIATE transaction, re-derive the state, and require byte equality. Losing CAS leaves only unreferenced GC candidates.
- Test doubles are correctly quarantined: `MemoryCredentialStore` (os_key_provider) and `TestKeys` (skill_tests) are `#[cfg(test)]`-scoped; `skill_tests`/`workspace_instruction_tests`/`workspace_root_membership` fixtures insert rows with raw SQL only for tables owned by other adapters. **No mock implements a production trait object in non-test code**, so test doubles cannot leak into runtime behaviour. The one adjacent risk is `workspace_root_membership`'s tests validating against a hand-written in-memory schema rather than the real migrations — divergence there would not be caught by those tests.
- Real divergence found: `discover.rs` `runtime_capability_entries()` swallows every `StoreError` via `unwrap_or_default()`, so a failed/unauthorized capability-host read is indistinguishable from "no hosts". Everywhere else in this bucket errors propagate. Worth an owner decision under `docs/CAPABILITY-FABRIC.md`.
- Duplicate digest validators: `storage_core::is_sha256_digest`, `environment.rs::valid_digest`, and `delegation_benchmark.rs::validate_sample`'s inline closure each re-implement `sha256:` + 64 lowercase hex. Same rule, three implementations — a drift hazard against the "one normative definition" invariant.
- `expect()` in load-bearing code: `delegation_benchmark::summarize_arm` (`median(...).expect("validated samples have latency")`, guarded by `validate_sample`), `windows-local-security` (`opened_directories.last().expect("just pushed directory")`), and `storage-sqlite::skill_tests` (tests only). No `unwrap()` on untrusted input was found in production paths reviewed here.
- Report-only code stays honest: `B83BenchmarkReport.automatic_selection_qualified` is hard-coded `false` and `decide_delegation_benefit` can only return a policy evaluation, not a selection — consistent with "an arm must use one exact runner configuration" and with not letting aggregation become an authority.
- Time authority: `expire_execution_lease` compares against `strftime('%Y-%m-%dT%H:%M:%fZ','now')` from SQLite, not the caller's timestamp, so clock skew cannot expire a live lease. Cursor/occurrence logic is clock-injected but never rewinds (`backwards_clock_never_rewinds_the_cursor`).
- Documentation-vs-code deltas worth noting: `storage-core::ResourceStore::create_derived_resource`, `reindex_resource_text` and `search_indexed_resource_text` ship as **default trait methods returning "unsupported"**, so implementing `ResourceStore` does not prove those capabilities exist — callers must not infer availability from trait membership.
