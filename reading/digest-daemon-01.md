## Cross-cutting observations
- Architecture as built: one process, one authenticated local IPC frame protocol, `axum::Router` used as an in-process service (`oneshot`), storage reached through `spawn_blocking` on `SqliteWorkspaceStore`; every route is Workspace-scoped by `X-Workspace-ID` and authorized by daemon-owned `principal_id`. No bearer token or HTTP listener exists — consistent with "local-first desktop, native handles never in projections".
- Two-tier authz (`authorized_workspace` vs `authorized_data_workspace`) is an explicit, documented divergence from a blanket binding check; the comment records that eight hand-written copies had already diverged.
- "Unknown is not success" is implemented literally: computer-use, ZIP intake, Coworker presence, OpenCode admission, Codex conversation eligibility and planning dispatch all return refusal/UNAVAILABLE rather than a fabricated success. This is a strong signal that TARGET-vs-evidence discipline reached the code.
- Copy drift risk: If-Match parsing exists in at least three places with different floors (`notification` allows 0 = "no policy", `coworker` and `parse_if_match` require > 0); cursor codecs are duplicated per route with slightly different version fields (`u8` vs `u32`).
- Blocking-in-async: `list_resources`, `resource_locations_response`, `read_resource_content`, `search_resources`, `list_agent_profiles`, `list_agent_bindings`, `enroll_local_runtime`, `rebuild_resource_text_index` call the store directly on the async thread instead of `spawn_blocking` (inferred risk, not measured).
- Probes still use `std::env::current_dir()` as the native probe cwd for Codex/OpenCode, whereas inventory probes deliberately use a non-workspace cwd; if the daemon cwd is a repository, a native CLI may read repository config during a probe (inference, requires confirmation).
- `resolve_local_executable` only checks canonicalize + `is_file()` (no execute bit) before handing the path to the probe; contrast with the stricter Unix inventory resolver.
- No `todo!()`/`unimplemented!()`/`TODO` was encountered in the ~14,000 lines read, but a bucket-wide grep could not complete before the deadline, so absence is **not** verified for `operator.rs` 7501–9525, `user_request_operator.rs`, or the test files.
