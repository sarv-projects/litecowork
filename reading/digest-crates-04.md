## Cross-cutting observations

- **Containment, answered honestly.** No file in this bucket enforces OS-level containment: no DACLs, no job objects, no namespaces, no cgroups, no process-tree kill. What exists is (a) **Unix IPC endpoint confinement** — `operator-ipc` tests assert `0o700` dir / `0o600` socket / inode-identity rebind refusal / peer-credential capture / `MAX_CONCURRENT_CONNECTIONS`; and (b) **database-level fencing** — `environment_control_lease` (epoch + `fencing_token_digest` + `issuer_key_version`), `workspace_root_observations` (per-`runtime_incarnation` binding joins), and `workspace_archive::blockers` (17 liveness predicates). The Windows side of the IPC story (named-pipe ACL) is not in this bucket, so any doc promise of DACL-confined Windows IPC is **unverified** from crates-04.
- `windows-local-security` / `linux-process-scope` / `local-environment-staging` were the brief's emphasis but are absent from this bucket's plan. I did not locate them; the one `find`/`grep` I attempted was cancelled at deadline, so I cannot state where they live (possibly outside `crates/`, e.g. `apps/` or `capabilities/`).
- **Fail-closed is the dominant style**: `default-src 'none'` with no invented fallback, `authoritative: false` always, `Dynamic` skills never activatable, unknown install state → `ERROR`, non-owner → `NotFound`, `CAPABILITY_DISPATCH_*` refusal codes. Two exceptions: quiet-hours `unwrap_or(false)` fails *open* toward delivery, and `trace_bytes`' `unwrap_or(0)` undercounts a budget.
- **One genuine spec/behaviour defect:** `resource-src` is not a CSP directive; the MCP App CSP therefore over-blocks declared `resource_domains` while the tests only string-match, so the mismatch is invisible to CI.
- **Honest capability-gap documentation** rather than stubs: both `skill.rs` (`LITESPM_PACKAGE_SERVICE_NOT_QUALIFIED`) and `capability_dispatch.rs` (`sqlite-v15.sql` guard, `implementation/reviews/E04-S03.md`) declare themselves blocked instead of simulating the missing wire contract. That matches the repo's "Unknown is not success" invariant.
- Layering is clean: `domain-*` crates hold pure decisions with trait ports and no persistence; `storage-core` holds records/guards/read models; `storage-sqlite` holds adapters and migration tests; `operator-ipc` holds transport. `domain-invocations` is dependency-minimal (serde only), which is consistent with a pure record crate.
- Divergence from ARCHITECTURE.md worth noting: `workspace_archive::blockers` queries tables owned by many domains (`effects`, `approvals`, `secret_leases`, `environment_control_leases`, `channel_host_assignments`) from inside the Workspace storage adapter. It reads, never writes, those aggregates — acceptable as a cross-domain *observation*, but it is a de-facto coupling point that a new domain must remember to extend.
