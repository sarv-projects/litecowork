# Reading notes

This directory is a non-normative repository-inspection workspace. Digests and indexes help navigate source, but may contain historical observations and must never override current owner contracts or active code.

For present product, UI and release truth, start at docs/README.md and follow the authority chain to docs/IMPLEMENTATION-STATUS.md and docs/schemas/served-route-inventory.json.

Files named digest-archive-* describe preserved history. Files named digest-docs-*, digest-specs-*, digest-daemon-*, digest-crates-* and digest-ui-* are snapshots of material read, not live source documents. Recheck source before reusing an observation.
