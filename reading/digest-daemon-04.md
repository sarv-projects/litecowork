## Cross-cutting observations

- **Uniform module shape.** Each operator module is its own `Router<XApiState>` with `XApiState { store: SqliteWorkspaceStore, principal_id: String }` plus `impl FromRef<ApiState>`, and a `#[cfg(test)]` companion (`test_router`, `*_router`, or `new`). Consequence worth flagging: `agent_registry_operator::routes()`, `runtime_capability_hosts_operator::routes()` and `resource_dependencies_operator::routes()` attach **no** `authenticate` layer themselves — authentication is the mounting parent's responsibility (`agent_control_operator.rs` and `discover_operator.rs` attach it internally). A mount outside the authenticated parent would be an unauthenticated route; this is inferred from the code, not proven by a test.
- **Error envelope is consistent:** `operator_error`/`operator_error_with_details` → `{code, message, …}`. Codes observed: `INVALID_ARGUMENT`, `NOT_FOUND`, `FORBIDDEN`, `CONFLICT`, `STALE_VERSION`, `STALE_WORKSPACE_VERSION`, `DEPENDENCY_UNAVAILABLE`, `INTERNAL`, `RUNTIME_MISMATCH`, `ROUTINE_ARCHIVED`, `ROUTINE_ARCHIVE_BLOCKED`, `WORKSPACE_ARCHIVED`, `AGENT_UNAVAILABLE`.
- **`Cache-Control: no-store` everywhere** on Workspace-derived reads and errors (per-response insert and/or `route_layer` middleware), consistent with "private Workspace state".
- **Idempotency is durable, not in-memory.** Receipts live in `request_dedup` keyed `(principal_id, request_id)` with `request_digest` + `response_json` + `response_digest = "sha256:<hex>"`. Verified semantics: exact replay returns a byte-identical body and preserves the original correlation id; changed payload → `409 CONFLICT`; stale version → no receipt written at all; replay still works after process restart **and** after store reopen. Receipt owners are checked — a receipt belonging to a different principal is treated as an error in the test helpers.
- **Fail-closed is systematic and honest.** `agent_control_operator` → 503 (no manufactured descriptor); `discover_operator` connect-or-install → 503 (`LITESPM_PACKAGE_SERVICE_NOT_QUALIFIED`) and test → `health: UNKNOWN`; `agents/planning` dispatch → always `Err`; `environment_office_qualification` → no qualified provider; `attempt_process_scope` → `#![allow(dead_code)]`. These are **CODE**-level stubs; none is SERVED or INTEGRATED product capability, and the code comments say so explicitly.
- **Cursor discipline.** Every list route encodes `b64url(JSON)` ≤2048 bytes carrying `version` + `workspace_id` and binding to the full filter tuple: search binds `(mode, q, kind, limit)` (proven by 400s on changed `q`/`kind`); registry binds `snapshot_digest + source_revision + query`; dependents binds `resource_id + limit`; capability hosts binds `runtime_incarnation_id` and returns `409 STALE_VERSION` when the incarnation moves.
- **Divergence / risk notes vs ARCHITECTURE.md invariants.** (a) `agents/planning.rs` states in its own header that it is *not* a global enforcement boundary and that native thread/turn constructors remain callable — so "Task admission is gated" is true only for this preflight path. (b) `attempt_process_scope` depends on `linux_process_scope`/systemd and is dead code, so Attempt containment is TARGET, not CODE, on Windows/macOS. (c) All restart/replay proof in this bucket is Unix-only (`std::os::unix`, uid peer checks, `rustix` signals); there is no Windows restart/replay evidence here. (d) `agent_registry_operator` performs an outbound HTTPS fetch to a third-party CDN; it is bounded and redirect-free but it is still Runtime→internet egress from the daemon.
- **Test scaffolding vs production.** Distinguish clearly: `resource_index_operator_tests`, `runtime_revalidation_tests`, `runtime_shutdown_tests`, `workspace_idempotency_key_bounds_operator_tests`, `workspace_root_selection_operator_tests`, and `runtime_workspace_replay_process_tests` are test-only files. The replay suite deliberately imports one production Tauri module (`conversation_create_journal`) but its own harness, `RuntimeChild`, and receipt readers are scaffolding. `attempt_process_scope`, `agents/planning` (`require_dispatch`, `packet`) contain `#[allow(dead_code)]` staged production code, not test code.
