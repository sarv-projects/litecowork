## E01-S01 — Contract/toolchain baseline

Dependencies: none.

**Implement:** Pin Rust/TS/Python toolchains and lockfiles; reproduce schema/API/SQL validator; create workspace build and lint CI without empty domain crates.

**Acceptance:** Clean checkout builds and validators pass; pipeline reports exact versions and skips no required contract check.

**Negative/race cases:** Missing toolchain, malformed schema, stale generated client, unsupported license.

**E01-S01-CODE:** Unit/property tests for the stated guards; contract request/response/event payload fixtures; real storage transaction checks. Assert the acceptance facts and rejection of every negative case above.

**E01-S01-SYSTEM:** Execute the implementation using its actual process/transport/provider. Inject the listed failures at before-admission, after-persist and before-response boundaries where meaningful; assert durable/UI/authority truth after restart. Record OS/build/provider versions.

**E01-S01-USER:** Reproduce build and contract checks in a disposable checkout. Owner checks expected outputs and permissions against a prepared oracle. Store a sanitized review packet. A mock-only run does not satisfy real-provider acceptance.

**Review gate:** Exact API/events/schema/SQL/projection references, changed paths, tests, telemetry, rollback and evidence must appear in the review packet. Decompose into smaller child stories if this cannot be demonstrated in one review cycle.
