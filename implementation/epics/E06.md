## E06-S01 — Bounded archive and extraction provider

Dependencies: E04-S05.

**Implement:** ZIP manifest preview and extraction limits; isolated type parsing/OCR provider; exact Resource revisions and parse provenance; run SP06.

**Acceptance:** Path traversal/symlinks/bombs refused; original immutable; PDF/page/table references retained; failures visible per file.

**Negative/race cases:** Nested ZIP, encrypted ZIP, Unicode duplicate path, zip bomb, malformed PDF, OCR timeout.

**E06-S01-CODE:** Unit/property tests for the stated guards; contract request/response/event payload fixtures; real storage transaction checks. Assert the acceptance facts and rejection of every negative case above.

**E06-S01-SYSTEM:** Execute the implementation using its actual process/transport/provider. Inject the listed failures at before-admission, after-persist and before-response boundaries where meaningful; assert durable/UI/authority truth after restart. Record OS/build/provider versions.

**E06-S01-USER:** Import mixed folder and ZIP without escape; inspect extraction report. Owner checks expected outputs and permissions against a prepared oracle. Store a sanitized review packet. A mock-only run does not satisfy real-provider acceptance.

**Review gate:** Exact API/events/schema/SQL/projection references, changed paths, tests, telemetry, rollback and evidence must appear in the review packet. Decompose into smaller child stories if this cannot be demonstrated in one review cycle.
