# E11 — Cloud continuation and messaging

Gate: Post-V1 Cloud. All stories initially PLANNED. This epic is explicitly excluded from
the desktop/local V1 release gate.

Contracts: [RUNTIME-MESH](../../docs/RUNTIME-MESH.md), [STORAGE](../../docs/STORAGE.md), [NETWORK-SECURITY](../../docs/NETWORK-SECURITY.md), [PROTOCOLS](../../docs/PROTOCOLS.md), [CHANNELS](../../docs/CHANNELS.md), [ENVIRONMENTS](../../docs/ENVIRONMENTS.md).

Reference sources: R-OPENCLAW, R-OPENHANDS in [catalogue](../SOURCES.md).

## E11-S01 — Cloud deployment and operations

Dependencies: E13-S04 (desktop/local V1 released).

**Implement:** Run SP07; deploy same daemon/container with persistent volume/health/resource limits/reverse proxy/TLS; use OpenClaw deployment references.

**Acceptance:** UI close does not stop cloud job; restart persists state; externally exposed control plane authenticated; cost caps documented.

**Negative/race cases:** Container killed, volume loss, auth misconfig, disk full, sandbox escape.

**E11-S01-CODE:** Unit/property tests for the stated guards; contract request/response/event payload fixtures; real storage transaction checks. Assert the acceptance facts and rejection of every negative case above.

**E11-S01-SYSTEM:** Execute the implementation using its actual process/transport/provider. Inject the listed failures at before-admission, after-persist and before-response boundaries where meaningful; assert durable/UI/authority truth after restart. Record OS/build/provider versions.

**E11-S01-USER:** Provision disposable server, run Task, restart and restore backup. Owner checks expected outputs and permissions against a prepared oracle. Store a sanitized review packet. A mock-only run does not satisfy real-provider acceptance.

**Review gate:** Exact API/events/schema/SQL/projection references, changed paths, tests, telemetry, rollback and evidence must appear in the review packet. Decompose into smaller child stories if this cannot be demonstrated in one review cycle.
