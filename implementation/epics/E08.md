## E08-S01 — Coworker identity and Home

Dependencies: E05-S05, E06-S05.

**Implement:** Revisioned Coworker/default lead/interaction defaults/primary selection, presence, Home hierarchy and allowlist worker assignment.

**Acceptance:** Pause blocks new proactive work not existing Tasks; archive guards primary/responsibilities; named composer with advanced controls.

**Negative/race cases:** Archived lead, multiple active Tasks, offline default path, stale assignment.

**E08-S01-CODE:** Unit/property tests for the stated guards; contract request/response/event payload fixtures; real storage transaction checks. Assert the acceptance facts and rejection of every negative case above.

**E08-S01-SYSTEM:** Execute the implementation using its actual process/transport/provider. Inject the listed failures at before-admission, after-persist and before-response boundaries where meaningful; assert durable/UI/authority truth after restart. Record OS/build/provider versions.

**E08-S01-USER:** Create Alex, assign cheap workers, start two Tasks and inspect status. Owner checks expected outputs and permissions against a prepared oracle. Store a sanitized review packet. A mock-only run does not satisfy real-provider acceptance.

**Review gate:** Exact API/events/schema/SQL/projection references, changed paths, tests, telemetry, rollback and evidence must appear in the review packet. Decompose into smaller child stories if this cannot be demonstrated in one review cycle.
