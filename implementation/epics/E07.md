## E07-S00 — Task-scoped local Environment isolation

Dependencies: E02-S03.

**Implement:** Add the local provider path for preparing an Environment from exact pinned
Resource revisions, staging immutable inputs read-only, separating bounded writable
outputs, enforcing OS-level filesystem/process/network restrictions, recording a private
Runtime-local isolation attestation, revalidating provider identity after restart, and
proving writer quiescence before reuse/cleanup. Keep native Task dispatch disabled until
the provider's actual OS qualification and the separate Trust/Effect/lease gates pass.
An ordinary directory or Git worktree is not a sandbox.

**Acceptance:** An admitted test process sees only authorized staged inputs and the
declared writable roots; exact Resource digests remain unchanged; writes cannot escape the
output root; child writers are fenced through an enforcing provider; unknown/unsupported
OS restrictions fail closed. No Attempt, AgentSession, or lease is created by this
provider-preparation story.

**Negative/race cases:** Foreign, missing, stale, duplicate, digest-mismatched, symlinked,
or traversal inputs; source changed during staging; permission denied; child process
survives parent exit; provider timeout after allocation; Runtime restart with stale
identity; unsupported OS mechanism; concurrent cleanup/use; unknown quiescence.

**E07-S00-CODE:** Unit/property tests for path normalization, exact-pin/digest checks,
input immutability, write-root boundaries, idempotency, restart identity, and fail-closed
unknowns. Contract fixtures bind the attestation to exact policy, Runtime incarnation,
Environment, Task, and execution identity.

**E07-S00-SYSTEM:** Run the enforcing provider and real child processes on every claimed
OS. Attempt reads/writes outside the roots, symlink escapes, network access, background
descendant writes, owner cancellation, daemon restart, and cleanup races. A mock provider
or source inspection is insufficient.

**E07-S00-USER:** Import a small real project Resource, prepare the Environment, inspect
the visible inputs/output location, attempt a harmless out-of-scope access, restart the
daemon, and verify safe recovery and cleanup. Record OS/build/provider versions and
sanitized evidence; this does not ask the owner to review internal sandbox code.

**Review gate:** Keep `PlanningCoordinator::require_dispatch()` closed until the system
qualification succeeds and Task admission consumes the attestation alongside current
Trust, Effect, lease, and Environment proofs.

**Source progress (2026-10-09, preparation-only / in progress):** A separate
`local-environment-staging` crate accepts only caller-resolved bytes for exact Workspace,
Resource, revision, and digest pins; it checks those digests and bounded file/count/path
limits, rejects traversal and cross-platform case-fold/path collisions, and stages sibling
files under shared directories. On Unix it creates a mode-restricted preview root with
read-only inputs and a distinct writable outputs directory. Non-Unix staging fails closed
until owner-only ACL behavior is qualified. A bounded adapter now accepts the selected
TaskView, strictly parses its closed `PinnedResourceRef` inputs, checks the requested Task
and spec revisions, resolves each exact revision through `ResourceStore`, validates the
returned Workspace/Resource/revision/size binding, and derives staged paths only from the
canonical stored display name. An SQLite integration test stages an older pinned revision
after the Resource head has advanced and proves that the historical bytes are used. The
result remains explicitly `PreparedOnly`: the helper is not called by an Operator flow or
provider, does not reauthorize the Workspace owner, and creates no Environment record,
provider binding, Attempt, AgentSession, lease, or dispatch. It does not enforce process,
filesystem, network, or output-quota isolation. Linux tests do not qualify Windows/macOS
or satisfy E07-S00 system/owner acceptance; dispatch remains disabled.

**Acceptance:** Private worktree vs retained browser semantics separate; no secret locator in events; persistent cost/ownership explicit.

**Negative/race cases:** Provisioning response loss, unhealthy environment, archive with reference, budget exceed.

**E07-S01-CODE:** Unit/property tests for the stated guards; contract request/response/event payload fixtures; real storage transaction checks. Assert the acceptance facts and rejection of every negative case above.

**E07-S01-SYSTEM:** Execute the implementation using its actual process/transport/provider. Inject the listed failures at before-admission, after-persist and before-response boundaries where meaningful; assert durable/UI/authority truth after restart. Record OS/build/provider versions.

**E07-S01-USER:** Prepare isolated checkout and retained container; restart and reuse safely. Owner checks expected outputs and permissions against a prepared oracle. Store a sanitized review packet. A mock-only run does not satisfy real-provider acceptance.

**Review gate:** Exact API/events/schema/SQL/projection references, changed paths, tests, telemetry, rollback and evidence must appear in the review packet. Decompose into smaller child stories if this cannot be demonstrated in one review cycle.

**Source progress (2026-10-09, partial/unverified):** A pure Environment lifecycle domain,
`EnvironmentStore` port, and SQLite lifecycle adapter now cover bounded listing, owner/
active-Workspace admission, immutable identity/config, request-receipt replay, event/blob
atomicity, current-incarnation provider bindings, CAS, active-Attempt checkpoint holds,
and v11-v13 migration rollback/retry. Focused Environment tests pass. The adapter
does not provision or destroy a provider, reserve persistent-environment budget, recover
an old-incarnation binding, expose an Operator API/UI, or execute an Attempt; destruction
fails closed without durable retention/output proofs. The F65 sharing-scope operation is
implemented in the Environment domain/SQLite path, but lacks an Operator API/UI and is
still fenced by existing hold proofs. This work does not complete E07-S01 or its
system/owner acceptance.
