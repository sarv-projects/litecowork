# E13 — Desktop/local V1 production release qualification

Gate: G3. All stories initially PLANNED. This epic qualifies the desktop/local product
only. Cloud continuation and remote Runtime are post-V1.

Contracts: [TESTING](../../docs/TESTING.md), [BENCHMARKS](../../docs/BENCHMARKS.md), [FAILURE-RECOVERY](../../docs/FAILURE-RECOVERY.md), [OBSERVABILITY](../../docs/OBSERVABILITY.md), [STORAGE](../../docs/STORAGE.md), [SECURITY](../../docs/SECURITY.md).

Reference sources: R-TAURI, R-OPENCLAW in [catalogue](../SOURCES.md).

## E13-S01 — Backup/restore and safe upgrades

Dependencies: E10-S02 (all finalized local feature epics).

**Implement:** Encrypted local manifest backup, migration/restore to a fresh desktop Runtime, tombstone/purge receipt preservation, upgrades/rollback and in-progress pins.

**Acceptance:** Restored Runtime new identity; no old authority resurrected; resource/artifact checksums verified; incompatible downgrade refused.

**Negative/race cases:** Interrupted backup, corrupt manifest, wrong key, schema mismatch, offline purge targets.

**E13-S01-CODE:** Unit/property tests for the stated guards; contract request/response/event payload fixtures; real storage transaction checks. Assert the acceptance facts and rejection of every negative case above.

**E13-S01-SYSTEM:** Execute the implementation using its actual process/transport/provider. Inject the listed failures at before-admission, after-persist and before-response boundaries where meaningful; assert durable/UI/authority truth after restart. Record OS/build/provider versions.

**E13-S01-USER:** Restore actual Workspace on clean install then resume eligible Task. Owner checks expected outputs and permissions against a prepared oracle. Store a sanitized review packet. A mock-only run does not satisfy real-provider acceptance.

**Review gate:** Exact API/events/schema/SQL/projection references, changed paths, tests, telemetry, rollback and evidence must appear in the review packet. Decompose into smaller child stories if this cannot be demonstrated in one review cycle.
