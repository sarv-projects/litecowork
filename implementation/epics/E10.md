## E10-S01 — MCP Apps/Skills and Discover

Dependencies: E09-S04.

**Implement:** Sandbox App frames/CSP/message bridge, MCP_SKILL manifest conformance, Discover status/grants/auth/install/version compatibility.

**Acceptance:** App cannot steal Operator credentials; exact-origin transport only; install metadata not authority; incompatible option disabled.

**Negative/race cases:** Forged app message, CORS escape, hostile manifest, missing package service.

**E10-S01-CODE:** Unit/property tests for the stated guards; contract request/response/event payload fixtures; real storage transaction checks. Assert the acceptance facts and rejection of every negative case above.

**E10-S01-SYSTEM:** Execute the implementation using its actual process/transport/provider. Inject the listed failures at before-admission, after-persist and before-response boundaries where meaningful; assert durable/UI/authority truth after restart. Record OS/build/provider versions.

**E10-S01-USER:** Render real compatible MCP App and deny out-of-scope tool action. Owner checks expected outputs and permissions against a prepared oracle. Store a sanitized review packet. A mock-only run does not satisfy real-provider acceptance.

**Review gate:** Exact API/events/schema/SQL/projection references, changed paths, tests, telemetry, rollback and evidence must appear in the review packet. Decompose into smaller child stories if this cannot be demonstrated in one review cycle.
