## Approval review and exact-action resolution UI CODE slice — 2026-10-17

Needs You now opens a Workspace-scoped Approval detail view instead of directing users to
an unmounted review surface. The Tauri bridge reads `GET /v1/approvals/{approval_id}` and
resolves through `POST /v1/approvals/{approval_id}/resolve`; it validates `no-store`, the
selected Workspace/Approval identity, Resource target, digest and state fields, and maps
only the closed Approval projection to the UI. The page presents the exact action, target,
risk, required assurance and expiry as inert text. APPROVE/DENY are unavailable while the
Runtime is offline or the Approval is not pending. The request sends `If-Match` from the
loaded Approval version, the exact action digest as the optional confirmation digest, and a
session-persisted idempotency key. Ambiguous failure keeps the same choice/key available;
refresh rereads the authoritative status. A confirmed decision closes the detail and
refreshes Needs You. The page states that resolving records a one-time decision and does
not itself grant reusable authority or execute an Effect.
