## Source increment (2026-10-16): immutable revision-history read path

The previously declared `GET /v1/delegation-profiles/{delegationProfileId}/revisions`
route now has a served implementation. SQLite performs owner-scoped, bounded,
descending revision paging inside a read transaction and omits the private `name_key`
projection. The authenticated Operator handler binds the opaque continuation cursor to
the current Workspace and profile, and returns `Cache-Control: no-store`. A finite
Tauri bridge, typed UI decoder, pagination checks, and an on-demand revision-history
disclosure connect that route to Agent Settings. Existing E03 installation-copy changes
in the shared AgentCatalog component were preserved.
