# E03-S09 partial CODE evidence — descriptor-backed credential snapshot

**Status:** Partial CODE only. The write-only SecretStore submission helper and typed
descriptor-to-snapshot conversion exist, and an authenticated no-store Operator route is
now served. There is no concrete AgentModule descriptor producer or durable replay receipt
for the keyring mutation, so the route returns a typed `DEPENDENCY_UNAVAILABLE` response
and never writes a credential. Native auth and credential submission remain unavailable
in the desktop product.

## Implemented

[`agent_credentials_operator.rs`](../../apps/litecoworkd/src/agent_credentials_operator.rs)
now converts a structurally valid, digest-verified, currently fresh
`AgentControlDescriptor` into the narrow snapshot consumed by the existing secret
submission boundary. It preserves the profile identity and descriptor digest, projects
only declared credential slot IDs, maps the exact secret kind/storage owner, and derives
the expiry from the descriptor timestamp. The converter rechecks descriptor integrity and
freshness at the supplied current time. It does not accept descriptor metadata from a
request body, persist secrets, or enable a handler without a trusted module source.

The existing write-only helper continues to zeroize submitted bytes, reject stale or
mismatched descriptors and unknown/native-owned slots, write directly to SecretStore, and
return only the opaque `SecretRef` projection. A SecretStore failure is reduced to the typed
`SecretStoreUnavailable` result; provider/storage error details are not returned. The new
route authenticates local IPC, sets `Cache-Control: no-store` on every outcome, bounds the
request body, verifies Workspace ownership and profile membership, validates the bounded
write-only payload, and asks only a Runtime-owned descriptor source. The current production
source returns unavailable because no trusted AgentModule producer is registered. Even if
one is later supplied, route-level writes remain disabled until a durable replay receipt can
make a lost response safe to retry.

unknown slot rejection, malformed base64, and zero secret echo. A new SecretStore failure

1 ignored** (255 filtered):

