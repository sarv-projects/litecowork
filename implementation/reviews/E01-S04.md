## Authenticated local Conversation stream CODE slice (2026-10-11)

reader. The strict subscription currently supports one `conversation_presentation` filter
and one Conversation ID. Unsupported Task, Runtime inventory, and multi-Conversation
filters fail explicitly. The stream session has its own two-session semaphore and uses the
documented 16 KiB subscription limit, 1 MiB frame cap, five-second per-message write
deadline, and shutdown watch cancellation.

The initial response is a correlated empty-body 200 handshake with the exact stream MIME,
followed by one length-prefixed `stream.ready` frame and a closed `projection` frame carrying

serializes projection refreshes so a slow consumer cannot accumulate an unbounded queue.
